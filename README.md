# Nicolas Diedrich — Portfólio

Portfólio pessoal desenvolvido para apresentar minhas habilidades, conhecimentos, projetos e informações profissionais na área de tecnologia e desenvolvimento web.

## 👨‍💻 Sobre o projeto

Este projeto consiste em um site de portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

O objetivo é apresentar de forma organizada minhas habilidades, conhecimentos, projetos e informações de contato, além de demonstrar meu aprendizado e evolução no desenvolvimento web.

## 🎯 Objetivos

- Apresentar minhas habilidades em desenvolvimento web.
- Mostrar meus projetos e trabalhos desenvolvidos.
- Destacar meus conhecimentos em tecnologia.
- Apresentar minhas competências e interesses profissionais.
- Disponibilizar informações de contato.
- Praticar desenvolvimento web e organização de projetos com Git e GitHub.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
